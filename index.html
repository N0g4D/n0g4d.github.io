Open source

My open-source work sits where enterprise delivery meets two other worlds: AI agents, and verifiable, privacy-preserving systems on EVM chains.

omega-connect

AI agents Tool connections for OmegaHive. Agents reach outside tools through MCP servers, and a person approves every write. github.com/N0g4D/omega-connect

An OmegaHive app for Omega, SingularityNET's open-source agent framework. It lets the minds in a hive use outside tools through MCP servers, with Microsoft 365 as the first showcase.

  • A tool counts as a read only after a person has reviewed it.
  • Every write waits for a named person's approval.
  • A tool whose definition changes drops back to write.

Demoed end to end on a live hive against a Microsoft 365 tenant: a Teams channel read, then an approved post.

Built with Python, MCP, Microsoft Entra OAuth, Microsoft Graph. Apache-2.0.

omega-mcp

AI agents An MCP client plugin for an Omega agent that runs on its own. github.com/N0g4D/omega-mcp

The agent gets three tools to list, inspect and call the MCP servers its operator configures. A tool that changes data is refused unless the operator allows it, and the plugin stays off until it is switched on.

Built with Python, MeTTa, MCP. Apache-2.0.

Ancorhash

Web3 B2B document notarisation on EVM chains with zero data leakage: the document never leaves the device. github.com/N0g4D/azure-web3-notarizer

Proof of existence and integrity for enterprise documents, without the compliance and UX hurdles of a typical Web3 application.

  • Zero data leakage. The SHA-256 digest is computed inside the browser with the native Web Crypto API. Only those 32 bytes reach the backend, written into the data field of an EIP-1559 transaction.
  • Gas-sponsored relayer. The organisation never touches a wallet, a private key or a token: the backend signs and pays. Verification is symmetric: recompute the hash, compare it on-chain, trust nobody.
  • Fiat-ready billing. A notarisation on Polygon mainnet costs around $0.0008 in gas, priced live from an on-chain estimate and a CoinGecko oracle.
  • Opt-in extraction. With explicit consent, Azure AI Document Intelligence turns a scanned form into typed values that a receiving system can check on upload.

At ETHRome 2026 I prototyped a Confidential RWA Vault on top of it: encrypted storage on Swarm, a queryable index with expiry on Arkiv, an ERC-721 anchor on Avalanche Fuji. Next: a hosted deployment on Azure Functions and an end-to-end demo driven by a Power Automate Desktop flow.

Atlantysm

Web3 A fully on-chain game in which every crystal is an account that plays on its own behalf. github.com/N0g4D/atlantysm

The MVP runs on MUD v2: every crystal is an ERC-6551 account, combat is commit–reveal, and 152 Foundry tests cover the contracts. There is no game server, and the client is only a view of the chain.

Now designing Season 0 on Sepolia: a single immutable contract where each crystal's element, level and mana stay encrypted with Zama's FHEVM, and a duel publishes only who won.

Built with Solidity, Foundry, MUD v2, FHEVM, React, viem.
