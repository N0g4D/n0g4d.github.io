open source

Ancorhash

Environmental compliance and Web3 notarizer. Tamper-evident field reports: the hash is computed locally, anchored on-chain, and the measured parameters are extracted with AI. My flagship open-source project — the clearest demonstration of how I build.

github.com/N0g4D/azure-web3-notarizer .NET 10 · React · Polygon

01

Zero-data-leakage anchoring

The SHA-256 digest is computed inside the browser via the native Web Crypto API. Only those 32 bytes reach the backend, written into the data field of an EIP-1559 transaction on Polygon. The document itself never leaves the operator's device — which matters when the report carries personal and commercially sensitive data.

02

Gas-sponsored relayer

The organisation never touches a wallet, a private key or a token: the backend signs and pays. A notarization on Polygon mainnet costs around $0.0008 in gas, priced live from an on-chain estimate and a CoinGecko oracle. Verification is symmetric — recompute the hash, compare it on-chain, trust nobody.

03

Opt-in AI extraction

With explicit consent, Azure AI Document Intelligence and a domain parser turn a scanned form into strongly-typed values — water temperature, pH, dissolved oxygen as decimals, not OCR noise. A receiving system can compare them against a threshold the moment the report is uploaded, instead of weeks later.
